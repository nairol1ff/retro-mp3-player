# ⚡ BR0_PLAYER // v2.1 ⚡

> **Older Brother Core style media player built with Python.**

Custom desktop MP3 player featuring an old-school console terminal UI, an interactive tracklist, and a neon green seek-bar. Perfect for a chill coding atmosphere late at night.



## 🛠️ Tech Stack & Features
- **UI Engine:** `customtkinter` (Dark hardware style without rounded compromises).
- **Audio Engine:** `pygame-ce` (Stable and ultra-fast MP3 playback decoding).
- **Interactive Tracklist:** Clickable scroll frame with auto-indexing logic (`idx=idx`).
- **Neon Seek Bar:** Fully drag-and-drop functional audio scrubbing with position track timers.
- **Auto-Advance:** Smoothly jumps to the next audio track upon completion.

## 👾 Installation & Run

1. Make sure you have **Python 3.10+** (Tested on 3.15-dev).
2. Install dependencies via terminal:
```bash
pip install customtkinter pygame-ce
```
3. Run the main executable script:
```bash
python retro_player_v2.py
```
